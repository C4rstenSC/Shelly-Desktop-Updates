# Shelly Desktop – Updates

Aktuelle Version: **0.3.3**

Öffentlicher Updatekanal mit verschlüsselten Paketen. Updates ohne GitHub-Anmeldung; Integritätsprüfung vor Installation.

0.3.3: Grundprogramm-Installer mit festem Ziel C:\Program Files (x86)\Shelly. Vorhandene Desktop-Verknüpfungen anhand ihres EXE-Ziels erkennen und anpassen. Bei geschütztem Ziel Windows-Administratorfreigabe für Kopiervorgang; Start anschließend aus ursprünglichem Benutzerprozess. Updateskript unterstützt geschützte Installationsverzeichnisse ebenfalls. Für eine Verlagerung der Installation einmal Installieren.cmd aus dem neuen Grundpaket ausführen. Build, vorhandene Kernprüfungen und PowerShell-Syntaxprüfung erfolgreich; kein Live-Test von Windows-Installation, COM-Verknüpfungen oder UAC.
